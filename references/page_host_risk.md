# 第X章 核心功能实现：主机风险与合规核查中心

## 3.1 模块概述
主机风险中心是本系统执行脆弱性评估和合规性审查的核心组件。该模块突破了传统漏扫工具单纯依赖 IP 地址的局限，针对企业级跨网段、虚拟化集群以及云原生架构，提供“扫描-定位-核查-跟踪”的全生命周期风险闭环管理。

## 3.2 核心子模块功能说明
### 3.2.1 风险台账 (Vulnerability Ledger)
- **多维资产对齐追踪**：针对大中型网络中常见的跨网段扫描与 IP 漂移问题，台账模块内置了资产对齐算法引擎。风险记录强制锚定底层物理 MAC 地址与网络设备接口，确保漏洞工单准确派发至对应资产。
- **全局漏洞图谱**统一直观展示受影响主机、CVE 编号、CVSS 风险评分及当前修复状态流转进度。

- **漏洞全生命周期管理**
自动识别“新增、已修复、未修复”状态，支持人工打标签和备注。

### 3.2.2 漏洞扫描引擎 (Vulnerability Scanner)
- **异构环境深度支持**：扫描策略兼容传统 Linux/Windows 物理机，并深度特化支持底层虚拟化架构（如 VMware ESXi）及容器节点的漏洞探测。
- **高并发防御性调度**：创建扫描任务时，系统允许精细化配置跨网段扫描的线程池大小与 I/O 超时阈值，防止高并发探测对生产网络造成拥塞。
- **丰富漏洞库**
海量漏洞与POC验证：强调集成360,000+ 漏洞库与 5000+ POC。扫描结果必须包含漏洞利用证明（如攻击 Payload、目标响应结果、关键参数）。
- **弱口令研判**
增加一个实用的专项工具Tab，支持手工输入目标应用与账号密码，系统返回登录校验结果。

### 3.2.3 周期漏扫与差异分析 (Scheduled Scanning)
- **精细化 Cron 调度**：支持基于标准的 Cron 表达式设定周期性扫描任务（如重保期间每日巡检，日常每周巡检）。
- **增量漏洞计算**：周期扫描自动触发 Diff（差异）计算引擎，UI 重点高亮展示“新增漏洞”与“已修复漏洞”，并生成安全态势趋势报表。

### 3.2.4 基线配置核查 (Configuration Audit)
- **工业级协议采集**：摒弃单一的 Agent 模式，系统支持通过 SNMPv3、SSH、WMI 等协议进行无代理（Agentless）并发数据采集。
- **合规标准映射**：内置丰富的安全基线检查字典，可针对操作系统密码策略、文件权限、服务开放状态（如 ESXi SSH 暴露状态）进行深层读取，并直接对标《网络安全等级保护》等合规要求输出核查报告。

## 3.3 前端渲染特色
- 在高并发数据量下，风险台账采用分页懒加载与数据防抖技术，确保百万级风险条目检索时的浏览器内存稳定性。
- 前端图表集成了 Echarts 的关系力导向图（Force-Directed Graph），可视化呈现某个漏洞在全网特定子网段的横向蔓延风险。
