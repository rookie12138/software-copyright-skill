# 第X章 核心功能实现：全天候攻击监测与主动防御体系

## 5.1 模块概述
本模块构成了系统的“实时作战中心”，负责全网攻击事件的识别、告警、响应与反制。通过融合被动监测（流量深度解析）、主动防御（实时Agent阻断）与诱捕防御（高仿真蜜罐），系统建立了一套纵深的战时防御闭环。

## 5.2 核心子模块功能详述

### 5.2.1 实时态势监测中心 (Monitoring Center)
- **多源数据聚类分析**：系统利用高性能事件处理流水线（Pipeline），对来自全网 Agent 的海量日志进行实时解构。通过聚类算法，将海量的碎片化告警整合为结构化的“攻击事件”，极大降低了管理员的审计压力。
- **攻击拓扑演进图**：首页监测界面以动态演进图形式展示攻击链路，直观呈现黑客从“资产发现”到“漏洞利用”再到“权限维持”的完整渗透过程。

### 5.2.2 工业级威胁告警矩阵 (Threat Alerts)
系统定义了 8 类核心威胁告警类别，确保覆盖所有主流攻击向量：
1. **应用漏洞类**：识别 SQLi、XCE、RCE 等针对 Web 应用的注入与溢出攻击。
2. **暴力破解类**：实时统计针对 SSH、数据库、管理后台的离散化登录尝试。
3. **异常通信类**：利用熵值分析算法，检出 C&C 指令传输及 DNS/HTTP 隐蔽隧道。
4. **横向移动类**：监测内网中的 WMI 执行、SMB 爆破及非授权的网络扫描行为。
5. **数据外泄类**：基于离群流量检测，识别大规模敏感数据下载及非常规跨网段传输。
6. **恶意代码类**：实时发现 WebShell 上传及持久化恶意软件的下发动作。
7. **中间件安全类**：识别针对 Nginx、Redis、Tomcat 等底层组件的未授权访问。
8. **诱捕告警类**：当黑客触碰系统预设的蜜罐诱饵时，触发最高优先级的阻断告警。

### 5.2.3 蜜罐诱捕防御体系 (Deception Defense)
系统内置了 6 类高仿真业务蜜罐，用于诱导黑客进行错误决策并复现攻击路径：
- **服务级诱饵**：模拟 SSH、MySQL、Redis 等标准系统服务。
- **应用级诱饵**：伪造带漏洞的 Web 后台、Git 仓库及 OA 办公系统。
- **文件级诱饵**：散播带有追踪代码的敏感虚假文档，监控黑客的离线阅读行为。

### 5.2.4 自动化阻断与 Agent 管理
- **自适应阻断策略**：当系统判定攻击置信度超过设定阈值时，自动下发封禁指令。支持基于攻击源 IP 指纹、TLS 签名及业务行为的多维度精准拦截。
- **分布式 Agent 架构**：采用 eBPF 等内核技术实现轻量化防护，支持 Agent 的全局心跳监测、静默升级及跨网段协同防御。

## 5.3 技术优势与安全性
- **高性能流水线**：后端采用非阻塞 I/O 与环形缓冲区（RingBuffer），支持在万兆带宽环境下实现毫秒级的事件响应。
- **联动防御机制**：通过统一的消息总线，将攻击特征实时同步至各子网出口探针，实现“一点发现，全网阻断”。
