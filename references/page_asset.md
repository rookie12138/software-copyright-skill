# 第X章 核心功能实现：全维度资产管理中心

## 2.1 模块概述
资产管理中心是本系统的底层核心模块，负责全网资产的自动发现、属性识别与风险画像。系统打破了传统的静态资产记录模式，通过探针感知与流量解构，实现了对“主机-网站-流量-攻击面”的四位一体化管理。

## 2.2 子模块功能详解
### 2.2.1 主机资产精细化管理
- **资产指纹识别**：系统能够自动识别主机的操作系统版本（如 Ubuntu 22.04、Windows Server 2012 R2）、硬件配置信息及唯一 UUID 标识。
- **Agent 存活监测**：实时展示各节点探针的运行状态，对于离线资产或异常资产及时触发预警。

- **跨网段 MAC自动识别**
强调“无Agent、无凭证探测”，跨网段识别设备 MAC 地址。
多网卡探测与精细化识别：精准识别主机CPU/内存/磁盘使用率、进程、自启服务。不仅识别服务器，还需包含 4W+ 弱点指纹库，识别“网络摄像头、打印机、路由器”等 IoT 设备。

### 2.2.2 网站资产自动化发现
- **业务画像**：系统通过 Web 爬虫与中间件指纹库，自动解析站点的应用框架（如 Spring Boot, Django）、Web 服务器类型（Nginx, IIS）以及 SSL 证书的有效期。
- **影子资产探测**：识别企业内网中未备案的“孤儿站点”与测试接口。

### 2.2.3 流量风险画像分析
- **多维协议解析**：实时解构全网流量，区分标准业务流量与潜在威胁流量（如隧道通信、非标端口数据传输）。
- **异常基线对比**：通过建立流量正常基线，自动识别流量激增或异常会话。

### 2.2.4 全球攻击面测绘
- **端口暴露监测**：实时监控资产对公网开放的端口情况，重点聚焦 3389(RDP)、445(SMB)、6379(Redis) 等高危入口。
- **暴露风险指数 (ESI)**：根据开放端口的权重、关联漏洞数及威胁情报，实时计算资产的暴露风险值。
- **暴露面/二级域名监测**
通过关键字、出口IP，一键收集单位外部信息、敏感代码、微信小程序，并支持子域名暴力扫描与 IP 反查。

- **网站资产相关度分析**
基于爬虫分析网页特征，结合“网段/域名”命中规则，发现影子资产。

## 2.3 技术特色
- **分布式扫描引擎**：后端采用高性能异步协程架构，支持跨网段的高并发资产扫描与指纹采集。
- **前端实时渲染**：使用 React 虚拟列表技术（Virtual List）展示万级资产台账，确保界面流畅不卡顿。
