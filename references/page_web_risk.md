# 第X章 核心功能实现：网站风险与全生命周期监测模块

## 4.1 模块概述
网站风险模块专注应用层面的脆弱性挖掘与实时防护。相较于底层系统的封闭性，网站是网络攻击的首要突破口。本模块集成了静态资产建档、动态安全扫描、高频状态监测与深度的自动化渗透测试功能，为 Web 应用提供从暴露面分析到漏洞闭环的完整解决方案。

## 4.2 核心子模块详述

### 4.2.1 网站台账 (Web Asset Ledger)
- **应用指纹智能识别**：自动探测目标站点的 Web Server（如 Nginx, IIS）、后端开发框架（如 Spring, Django）、前端依赖组件以及 SSL 证书有效状态。
- **跨层级链路映射**：破除“只看域名”的局限，自动映射 Web 服务与其底层承载服务器 IP 之间的关系，形成立体的资产拓扑，方便在发生安全事件时迅速定位到物理或虚拟节点。

### 4.2.2 深度漏洞扫描引擎 (Web Vuln Scan)
- **现代 SPA 架构解析**：内置无头浏览器（Headless Browser）爬虫引擎，完美支持 Vue/React 等单页动态应用的深度路由抓取，杜绝传统爬虫漏抓页面的情况。
- **全方位漏洞特征库**：覆盖 OWASP Top 10，支持包括 SQL 注入、跨站脚本 (XSS)、XML 外部实体注入 (XXE)、以及高危的反序列化漏洞的自动化探测与验证。

### 4.2.3 安全监测中心 (Security Monitoring)
- **重保态势高频监测**：系统专为重要活动期间（如“重保”防御）设计了增强监测模式。开启后，探测频率提升至分钟级，并锁定页面的 DOM 树基线，一旦出现微小的非授权结构变化，立即触发告警。
- **暗链与篡改双擎核查**：基于“视觉截图相似度比对”与“敏感词/非法外链 NLP 提取”的双引擎，确保网站不被植入博彩、涉黑等恶意暗链。

- **敏感文件敏感词核查**
自动扫描互联网及 Web 目录下的 PDF/Word/Excel，识别“身份证、邮箱、手机号”泄露。


- **高可用性保障 (SLA)**：实时统计站点的首字节时间 (TTFB) 与 HTTP 状态码，防范应用层 CC 攻击导致的拒绝服务。

### 4.2.4 自动化渗透测试 (Automated Pen-Testing)
- **攻击链路模拟**：支持将孤立的漏洞信息串联，自动推演“突破边界 -> 提权 -> 内网横向移动”的攻击路径，在界面中以可视化图谱呈现。
- **盲打漏洞无损验证 (OOB)**：内建带外数据（Out-of-Band）接收模块（集成 DNSLog/HTTPLog 机制），可安全地验证无回显型的深层次漏洞（如 Blind SSRF 导致探测内网网段），而无需对生产业务产生任何破坏性影响。

- **渗透测试台账导入**
支持导入外部 Excel 报表，通过可视化图表展示漏洞比例，并跟踪处置进度（未整改/已整改/忽略）

## 4.3 技术特色
- 监测引擎使用高并发异步 I/O (Asyncio) 机制进行批量巡检，保证在大规模站点监测任务中，极大地降低系统资源消耗并提升告警的即时性。
- 代码层面对误报处理进行了深度优化，允许管理员对特定站点的动态元素（如滚动广告、时间戳）配置 DOM 忽略规则，保障监测准确率。
