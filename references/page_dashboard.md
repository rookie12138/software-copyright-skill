# 第X章 核心功能实现：首页态势感知中心

## 1.1 模块概述
首页作为本系统的核心态势感知中心，集成了资产分布、威胁监测、漏洞风险与系统状态的实时总览。通过高度可视化的仪表盘，管理员可快速掌握全网安全状况。

## 1.2 核心展示内容
### 1.2.1 关键业务指标 (KPI)
系统首页实时汇总并展示以下工业级资产数据：
- **受控主机资产数**：全网已部署探针并纳入管理的服务器、工作站总数。
- **高危风险资产数**：当前存在未修复关键漏洞或正在遭受攻击的资产总数。
- **实时威胁告警数**：最近24小时内系统拦截或发现的攻击事件总量。

### 1.2.2 威胁趋势分析
通过集成高性能 Echarts 引擎，首页动态呈现以下趋势：
- **流量攻击趋势图**：以 5 分钟为粒度统计全网入站/出站流量波动，识别异常流量峰值。
- **风险等级分布图**：按“危急、高危、中危、低危”四个维度展示资产健康度占比。

### 1.2.3 实时攻击监测列表
实时滚动展示全网最新的安全事件，单条记录包含以下元数据：
- **源 IP 地址**：攻击发起方，支持地理位置逆向解析。
- **攻击载荷/类型**：如 SQL 注入、跨站脚本、暴力破解等。
- **处置状态**：拦截中、已阻断、已放行或已隔离。
- **三维一体监测中心**
统一展现蜜罐告警、主机威胁、流量检测，支持关联分析提升可信度，攻击拓扑与时间轴全景展示。

## 1.3 前端技术实现
### 1.3.1 工业级组件化架构
- **Index View**: 采用 Flexbox 与 CSS Grid 构建响应式布局，确保在 1080P 与 4K 屏下均能完美适配。
- **Reactive State**: 使用 Zustand 进行状态分发，确保当 WebSocket 接收到新的威胁事件时，首页图表能够实现毫秒级局部刷新，无需重新加载页面。

### 1.3.2 去AI化代码特征
在实现过程中，前端代码遵循以下严格规范：
- **强类型接口约束**：定义 `interface InventorySnapshot` 与 `interface SecurityAlert`，确保数据流的可追溯性。
- **精细化错误拦截**：对图表渲染失败、API 超时等异常场景均实现 UI 级的兜底逻辑。
